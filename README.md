# Bank-Marketing-Power-BI-Dashboard
Power BI dashboard analyzing bank marketing campaign performance and customer subscription trends

## PROJECT OVERVIEW
This Power BI dashboard analyzes customer demographics, campaign performance, and customer subscription trends using the bank marketing dataset

## KEY MATRICS
- Total customer: 41K
- Subscribed customers: 5K
- Subscription rate: 11.27%
- Average age: 40 years

## KEY INSIGHTS
- Admin is the largest customers segment
- Married customers from the majority of customers
- University educated customers dominate the dataset
- Cellular contact generated the highest subscription
- May recorded the highest number of successful subscription
- Most previous campaign outcomes were categorized as non-existent

- Power BI
- Power query

- Data visualization
